# 超级大乐透 · 历史数据统计分析

一个基于**中国体彩网官方开奖数据**的大乐透（Super Lotto）全量历史数据统计分析 Web 应用。

数据覆盖 **2007-05-30 第 07001 期至今的全部开奖记录（2900+ 期）**，每期包含：开奖号码、出球顺序、摇奖球套号、当期销量、开奖前后奖池滚存、全部奖级的中奖注数与单注奖金、派奖活动标记。

> ⚠️ **免责声明**：本项目仅作历史数据的统计与可视化展示。彩票每期开奖相互独立、完全随机，历史频率与"期望值"的偏离**不构成任何预测价值**。请理性购彩，量力而行。本项目与官方无任何隶属关系。

---

## 功能模块

### 1. 📊 号码期望总览
- 前区（1-35）、后区（1-12）每个号码的实际出现次数 vs **理论期望值**（期望 = 期数 × 单球概率，前区 5/35、后区 2/12）
- 热号 / 冷号 / 当前遗漏 / 历史最大遗漏排行榜，偏离期望百分比
- 卡方（χ²）均匀性检验值
- 统计范围可切换：全部 / 近 3 年 / 近 1 年 / 仅第 1、2、3 套球

### 2. 📈 奖池 / 销量 / 一等奖奖金走势
- 全部期数的奖池滚存、单期销量、一等奖单注奖金走势曲线
- 悬停查看任意一期的具体数值与派奖标记

### 3. 🎱 球套分析
- 官方每期随机启用 3 套摇奖球之一（自 2011 年第 11006 期起有记录）
- 每套球独立的**热号 / 冷号排行**（按各套自身期望值判定）
- **跨球套冷热对比热力表**（前区 35 × 3 套、后区 12 × 3 套），自动标注跨套分歧最大的号码
- 自动总结：三套球一致偏热 / 偏冷的号码、分歧结论

### 4. 📜 规则 / 派奖 / 影响因素
- **规则时代时间线**：由数据自动识别出 3 个规则时代（2007 版 6 奖级+追加、2019 版 9 奖级、2026 版 7 奖级）
- **历年派奖活动**：自动识别连续派奖区间（2021-2026 共 6 轮、141 期），含一等奖中出注数与专项派奖总额
- 归纳全部可能改变奖金的因素：奖池滚存、中奖注数均摊、销量、派奖活动、追加投注、规则调整、固定/浮动奖机制、球套

### 5. 🗂 全部开奖记录
- 2900+ 期完整记录，支持按期号 / 日期 / 号码搜索
- 逐期展开查看完整奖级明细（派奖行高亮）、销量、奖池、出球顺序

### 6. 🎯 预测与期望值（数学科普向）
- 明确数学事实：每个组合中奖概率相同（1 / 21,425,712），号码不可预测
- 娱乐演示：热号延续 / 冷号回补 / 纯随机机选 / **低撞号机选**四种参考号码
- **实证返奖率**：用真实数据计算各时代每注 2 元的期望回报（约 53%）与期望亏损
- 数学推导为什么"追加投注"是单位期望最高的买法（实测追加奖金 = 基本的 80%，成本仅 +50%）
- 各种买法（单式 / 追加 / 复式 / 胆拖 / 倍投 / 合买）期望值对比表

### 7. 🧮 奖金计算器
- 默认载入最近一期，可切换任意历史期（2019 年起），按**该期官方公告的真实奖级金额**计算
- 覆盖全部玩法：**单式、复式（前区/后区/双区）、胆拖、追加投注、多倍投注**
- 自动按所选期号切换 2019 规则（9 奖级）/ 2026 规则（7 奖级，13 种中奖条件）
- 复式/胆拖自动展开组合并累计多奖级命中；派奖期自动叠加派奖奖金
- 与"预测与期望值"页签打通：参考号码可一键带入验算

### 8. 🔄 数据自动同步
- 页头「同步最新开奖数据」按钮：开发服务器内置同步接口直连官方数据源，**增量抓取**新期数并回写本地数据文件，全站统计即时刷新
- 最多自动回看 500 期衔接本地数据，久未使用也能一键补齐

## 技术栈

- **前端**：React 19 + TypeScript + Vite 7 + Tailwind CSS + shadcn/ui + Recharts
- **数据**：中国体彩网官方开奖公告接口（`webapi.sporttery.cn`），清洗后为单一 JSON
- **同步**：Vite 开发服务器中间件（Node.js）直连官方接口，规避浏览器 CORS 限制

## 本地运行

```bash
npm install
npm run dev        # 开发模式，默认 http://localhost:3000
npm run build      # 生产构建 -> dist/
npm run preview    # 预览生产构建
```

> 数据同步按钮依赖开发服务器中间件（`/api/sync-draws`），请在 `npm run dev` 模式下使用；
> 纯静态部署（如 GitHub Pages）时同步按钮不可用，数据为构建时快照。

## 数据更新（命令行方式）

```bash
python scripts/download_dlt.py   # 从官方接口下载全部历史数据 -> data/raw/
python scripts/clean_dlt.py      # 清洗校验 -> data/dlt_clean.json
cp data/dlt_clean.json dlt-app/public/data/   # 更新应用数据
```

## 数据字段说明

| 字段 | 含义 |
|---|---|
| `num` / `date` | 期号 / 开奖日期 |
| `front` / `back` | 前区 5 个 / 后区 2 个开奖号码（升序） |
| `order` | 出球顺序（7 个） |
| `equip` | 摇奖球套号（1/2/3，0 = 官方无记录，2011 年前） |
| `promo` | 是否为派奖活动期 |
| `sales` / `poolBefore` / `poolAfter` | 当期销量 / 开奖前奖池 / 开奖后奖池 |
| `prizes[]` | 全部奖级：名称、单注奖金、中奖注数、派奖总额（含追加与派奖行） |
